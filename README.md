# Fieldwork UI

A small, considered React component library built with Vite and documented in Storybook. Fieldwork pairs practical interface patterns with an editorial palette, warm typography, and a little personality.

## Run locally

```sh
npm install
npm run dev
```

## Explore the component stories

```sh
npm run storybook
```

When deploying the gallery, set `VITE_STORYBOOK_URL` to the published Storybook URL so its documentation links point to the hosted stories.

## Build and check

```sh
npm run build
npm run build-storybook
npm run lint
```

## Components

- Button
- Avatar group
- Badge
- Search input
- Segmented control
- Toggle
- Progress ring
- Stat card
- Project card
- Toast notification
